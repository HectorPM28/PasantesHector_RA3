Controls:

· E: Interact with NPC.

· A/D, left/right arrow: Horizontal movement.

· Spacebar: Change gravity.

· Esc key: Pause game.
 
The game is a platformer based on the designs from the SpongeBob SquarePants series.
You play as Patrick, a hungry star with no eyes that has to adventur itself through bottom bikini to try to find a crabby patty to satiate its hunger.
